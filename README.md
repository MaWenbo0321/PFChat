# PFChat

PFChat 是一个跨文化语用训练系统。用户通过与 LLM 角色对话，练习在不同语言、关系和场景中表达请求、拒绝、感谢、道歉及其他交际意图。系统关注表达是否符合当前关系、礼貌程度和文化预期，并给出修改建议与解释。

## 系统用途

语言学习者常常能写出语法正确的句子，却仍可能因为措辞、礼貌策略或关系判断不合适而造成误解。PFChat 把这类问题放进连续对话中进行训练，让用户观察一句话在具体场景下可能产生的效果。

系统主要支持两种训练方向：

- 用户使用目标语言与 LLM 交流，系统分析用户的语用表达。
- LLM 模拟二语学习者，用户作为听者识别其表达中的语用问题。

## 账号与界面语言

用户可以注册、登录和退出账号。注册时需要填写所属国家或地区，系统会使用这项信息设置默认界面语言，并为语用分析提供语言文化背景。

界面支持简体中文和英文。用户可以在登录页、会话设置页及聊天页切换语言。

## 会话设置

每次训练开始前，用户需要配置一组会话条件。系统将这些条件加入 LLM 对话和语用分析上下文。

### 练习模式

#### 用户作为二语学习者

用户使用目标语言发言，LLM 以熟练使用者的身份回应。系统分析用户当前发送的消息，判断表达是否符合双方关系和对话场景。LLM 保持自然交流，不会在聊天内容中直接打断用户进行纠错。

#### LLM 作为二语学习者

LLM 使用目标语言模拟二语学习者。生成回复前，模型会从内部知识中检索符合双方文化背景、关系、话题和当前消息的语用失误案例，再选择一个合适的模式融入角色表达。系统分析 LLM 的回复，并向用户说明听者可能怎样理解这句话、问题出现在哪里，以及可以观察哪些语用线索。

### 目标语言

当前可选择的练习语言包括：

- 英语
- 中文
- 日语
- 韩语
- 法语
- 德语

### 人际关系与话题

用户可以设置陌生人、同学、同事、朋友、师生等关系，也可以选择日常交流、学术、商务、旅行或文化交流话题。

系统会结合关系远近、权力差异和场景正式程度判断表达是否合适。同一句话在朋友之间可能自然，在商务或师生场景中则可能显得过于直接。

### LLM 角色

系统提供多组 LLM 角色。每个角色具有姓名、年龄、性别、国家或地区、性格特点及生活背景。角色来自日本、韩国、中国、蒙古、马来西亚、新加坡、德国、法国、美国、尼日利亚、巴西、澳大利亚、南非、印度和墨西哥等文化背景。

LLM 会在对话中保持所选角色的表达习惯、兴趣和互动倾向。在 LLM 二语学习模式中，系统还会避开与用户国家及目标语言主要国家相同的学习者背景，使二语身份与训练场景保持一致。

## 对话功能

聊天页显示当前会话的关系、话题、练习模式、目标语言、LLM 角色和对话轮数。LLM 会参考最近的聊天记录生成回复，使连续对话保持上下文一致。

系统按一条用户消息和一条 LLM 回复计算一轮。发送过程中会显示 LLM 输入状态，并在请求失败时保留用户尚未成功发送的内容。刷新聊天页后，系统可以恢复当前账号的活跃会话及已有消息。

同一用户只保留一个活跃会话。用户结束当前会话后才能从聊天页开始下一场训练。

## AI 语用建议

用户可以在创建会话时开启或关闭 AI 语用建议。

开启后，系统会分析训练对象的表达并生成反馈。关闭后，系统不会执行语用检测、生成总结或保存语用反馈记录，但 LLM 对话仍需调用模型生成回复，聊天消息也会继续保存。

## 反馈方式

### 每轮反馈

系统在每轮对话完成后分析当前训练对象：

- 用户二语模式分析用户消息。
- LLM 二语模式分析 LLM 回复。

每轮反馈会显示分析目标、原始消息、错误类型、修改建议和解释。没有发现明显问题时，系统会给出无明显语用失误的结果。模型服务不可用或返回内容无法解析时，界面会标记本轮检测不可用，不会把失败结果当作“没有问题”。关闭反馈窗口后可以继续对话。

### 完整会话反馈

完整会话模式会在用户手动结束会话或十分钟倒计时结束时生成总结。系统读取整场对话，概括整体表现，并选取最多六个有代表性的问题进行说明。

会话总结关注表达方式、关系处理、礼貌程度和文化预期。系统不会为每句话重复创建一条总结记录。

## 语用问题分类

PFChat 使用以下分类记录分析结果：

| 类型 | 含义 |
| --- | --- |
| 语用语言失误 | 措辞、句式或表达策略影响了请求、拒绝、感谢、道歉等交际意图 |
| 社会语用失误 | 表达错误判断了社会距离、权力关系、文化规范或场景要求 |
| 严重语用语言失误 | 表达形式可能造成明显冒犯、误解或沟通中断 |
| 严重社会语用失误 | 对关系或社会规范的判断可能造成明显冒犯或关系冲突 |
| 语用语言失误和社会语用失误 | 同一句表达同时存在语言策略和社会关系判断问题 |
| 无明显语用失误 | 完整会话中没有发现需要单独记录的明确问题 |

系统还会把结果标记为良好、可改进或问题较严重。普通语法、拼写和词汇问题只有在影响意图、礼貌或理解时，才会进入语用反馈。

## 反馈记录

用户可以在反馈记录页查看个人历史记录。页面提供以下功能：

- 查看记录总数、今日数量和本周数量。
- 查看可改进问题与严重问题的统计。
- 按语用问题类型筛选记录。
- 搜索原始对话、修改建议、解释或反馈来源。
- 区分用户消息、LLM 模拟学习者和完整会话反馈。
- 复制修改建议。
- 手动调整记录的问题类型。
- 删除单条记录、清空某一类型或清空全部记录。

相同文本出现在不同消息或不同会话中时，系统会保留各次记录，方便用户观察重复出现的问题。

## 管理员功能

管理员控制台用于管理系统账号和查看使用规模。管理员可以：

- 查看用户总数、管理员数量、消息数量和语用反馈数量。
- 搜索用户并分页浏览账号列表。
- 将普通用户提升为管理员，或将管理员降为普通用户。
- 删除用户及其会话、消息和反馈数据。

管理员不能修改自己的角色，也不能删除自己的账号。系统 LLM Bot 不会出现在普通用户管理列表中，管理员无法删除 Bot 或修改其角色。

## 数据与隐私边界

系统会保存账号信息、国家或地区、会话设置、聊天消息和生成的反馈。密码经过加密后保存。

LLM 需要接收会话条件、近期聊天内容和当前消息来生成回复。开启 AI 语用建议后，模型还会接收分析所需的角色、关系、场景和对话内容。用户应避免在训练对话中填写密码、证件号码、联系方式或其他敏感信息。

## 使用流程

1. 注册或登录账号，确认界面语言。
2. 选择练习模式、目标语言、LLM 角色、关系和话题。
3. 选择每轮反馈或完整会话反馈，也可以关闭 AI 语用建议。
4. 与 LLM 完成多轮对话，按所选方式查看反馈。
5. 结束会话并查看总结，随后在反馈记录页回顾历史问题。

## 功能边界

PFChat 用于语言学习和跨文化语用训练，分析结果可能受到模型输出质量和上下文长度影响。系统给出的建议适合作为练习参考，不代表某个国家、地区或群体中的所有人都会采用同一种表达方式。

系统只分析与交际意图、礼貌、关系和理解有关的问题。需要系统性语法教学、专业翻译或正式文化咨询时，用户仍需使用相应的学习资料或专业服务。
